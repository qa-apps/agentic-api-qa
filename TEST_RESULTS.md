# Agentic QA test results

Open the latest visual report:

## [OPEN THE LATEST VISUAL REPORT →](http://127.0.0.1:9324/)

Direct URL: <http://127.0.0.1:9324/>

Click either link above; do not type `reports/index.html` into Google. The localhost
report server starts automatically after every completed workflow run.

`reports/index.html` is updated automatically after every completed workflow run,
including runs started from LangSmith Studio. Historical reports remain under
`reports/qa-report-<run-id>.html`, and the matching machine-readable result is
available as `reports/latest.json`.

From a terminal, the same report can be opened with:

```bash
agentic-api-qa-report
```
